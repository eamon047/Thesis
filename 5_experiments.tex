\subsection{Experimental Setup}

The experiments use FB15k-237, which contains 14,541 entities and 237
relations. Its training, validation, and test sets contain 272,115, 17,535,
and 20,466 triples, respectively. We consider two KGE model families, RotatE
and TransE. They provide two different model settings for checking whether the
observed relation-level patterns are specific to one embedding model.

For each model family, one trained model is first used as the reference model.
Additional models are then trained with the same model configuration and
different random seeds. Let \(H_0\) be the filtered Hits@10 of the reference
model and \(H_i\) the filtered Hits@10 of a candidate model. A candidate is
included in the comparable model set when
\begin{align}
    |H_i-H_0| < \epsilon,
    \qquad \epsilon=0.01.
\end{align}
This process is repeated until the model outputs required for the multiplicity
analysis have been collected. Figure~\ref{fig:experimental-workflow} summarizes
this procedure. The performance condition keeps the comparison focused on
models with similar aggregate link-prediction performance, while the different
random seeds allow their query-level decisions to vary.

All link-prediction outputs are evaluated under the filtered setting with
\(k=10\). The analysis uses the raw outputs before voting aggregation, denoted
by the \texttt{without} condition in the experiment files. For each relation,
we report the relation-level Hits@10, ambiguity, and discrepancy defined in
Chapter~\ref{chap:framework}. The main figures and grouped comparisons retain
relations with at least ten test triples
(\(\texttt{test\_support}\geq 10\)); relations below this threshold are not
used in the displayed comparisons.
