\begin{eabstract}
Knowledge graph embedding models predict missing links by ranking candidate
entities for incomplete triples. Their overall performance is usually
summarized by aggregate top-10 accuracy (Hits@10). This aggregate value does
not show whether similarly performing models make the same top-10 decision for
each query. Previous work introduced predictive multiplicity and showed that
similarly performing KGE models can produce different predictions for the same
query. However, this instability was summarized at the global model level,
leaving open whether it varies across relation patterns.

This thesis examines predictive multiplicity at the relation level using the
FB15k-237 knowledge graph dataset and repeated runs of two KGE model families,
RotatE and TransE. We evaluate relation-level top-10 accuracy together with two
measures of disagreement across runs, ambiguity and discrepancy. We compare
these outcomes across three relation patterns: whether a relation connects one
or many entities on each side (mapping type), whether a different relation
connects the same entities in reverse order (inverse), and whether the relation
itself connects entity pairs in both directions (symmetry). The results show
that prediction instability differs across relation patterns in both models,
most clearly for mapping type. This relation-level view may help future work
target the relations and prediction directions where instability is
concentrated.
\end{eabstract}
