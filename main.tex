\begin{eabstract}
    This thesis studies the complexity and optimality of Follow-the-Perturbed-Leader (FTPL) policy in the $K$-armed bandit problem. 
    In this problem, a player repeatedly chooses one of $K$ arms and observes only the loss of the chosen arm, where the loss is generated from the environment in either stochastic or adversarial setting. 
    The objective of the player is to minimize the cumulative loss over all rounds. 
    Despite the widespread use of Follow-the-Regularized-Leader (FTRL) policy, which provides good theoretical guarantees on cumulative loss in both stochastic and adversarial settings, it requires solving an optimization problem at each round, leading to a high computational cost. 
    % In practice, policies that perform well in both settings are desirable since the nature of the environment is often unknown. 
    % This is a status known as Best-of-Both-Worlds (BOBW), and it can be achieved by some policies such as Follow-the-Regularized-Leader (FTRL). 
    % However, FTRL requires solving an optimization problem at each round, which can be computationally expensive. 
    In light of this limitation, FTPL policy, which efficiently chooses an arm with perturbed cumulative loss, has gained wide attention since it has good theoretical guarantees in both stochastic and adversarial settings without solving an optimization problem.
    % FTPL is a promising policy that achieves the Best-of-Both-Worlds (BOBW) guarantee without solving an optimization problem unlike Follow-the-Regularized-Leader (FTRL). 
    However,
    %there exists an obstacle that
    FTPL needs a procedure called geometric resampling to estimate the loss, which needs $O\qty(K^2)$ per-round average complexity, usually worse than that of FTRL. To address this issue, we propose a novel technique which we call Conditional Geometric Resampling (CGR). This is a technique for unbiased loss estimation applicable to general perturbation distributions, reducing the average complexity to $O\qty(K\log K)$ without sacrificing the theoretical guarantees.
    We also propose a biased version of CGR that can control the worst-case complexity without sacrificing the theoretical guarantees for a certain perturbation distribution. 
    We confirm through experiments that CGR does not only significantly improve the average and worst-case runtime but also gains lower cumulative loss thanks to the stable loss estimation.
\end{eabstract}
