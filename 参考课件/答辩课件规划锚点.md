# 答辩课件规划锚点

## 1. 文档用途

本文档用于在后续制作答辩课件时恢复讨论上下文，固定已经形成的范围、结构和取舍。

- 这是内部工作记录，不是课件文案。
- 不在这里详细填写讲稿、表格数值或逐句内容。
- 后续如有新决定，应更新本文档，避免依赖聊天记录长度。

## 2. 基本条件

- 场景：硕士论文答辩。
- 论文介绍时间：约 15 分钟。
- 主题：知识图谱嵌入链接预测中的 relation-level predictive multiplicity。
- 目标：让听众理解问题来源、研究问题、实验范围、三个结果及其证据边界。
- `参考课件/1.pdf` 至 `8.pdf` 只作为学生课件参考，不视为标准答案。
- `参考课件/0.pdf` 是旧版发表课件，只作为素材库和结构参照，不作为直接修改的母版。

## 3. 总体叙事

建议保留六个逻辑部分，但不一定为每一部分单独制作章节页：

1. Background：knowledge graph、KGE 与 link prediction。
2. Prior work：predictive multiplicity、原论文的主要工作。
3. Research question / analysis axes：从全局现象转向 relation-level structural analysis。
4. Experimental setup：说明当前论文实际采用的实验流程和条件。
5. Results：Result 1、Result 2、Result 3。
6. Conclusion and future work。

其中，Preliminaries 与 Prior Work 不完全相同：前者负责必要概念和定义，后者负责已有研究及研究缺口。

## 4. 页级范围

预计正文约 12 页，另加参考文献和答疑附录。页数可在制作时小幅调整。

| 页码（暂定） | 页面任务 | 布局方向 |
| --- | --- | --- |
| 1 | 标题 | 保持简洁 |
| 2 | KG、KGE link prediction、Hits@10 | 图示为主，建立任务概念 |
| 3 | Predictive multiplicity、Alpha、Delta | 使用同等总体性能但 query-level 决策不同的例子 |
| 4 | Prior work 与 thesis gap | 从原论文已经解决的问题过渡到本论文问题 |
| 5 | Research question 与 analysis axes | Mapping、inverse、symmetry；relation frequency 单列为待定控制因素 |
| 6 | Experimental setup | 用流程图交代数据、模型、重复运行、指标计算和 relation-level 聚合 |
| 7 | Result 1 第一页 | Mapping type 的核心结果，优先展示主要 prediction side |
| 8 | Result 1 第二页 | Head/tail 反转及 RotatE/TransE 的跨模型确认 |
| 9 | Result 2 | Inverse-like support，使用与 Result 3 一致的页面模板 |
| 10 | Result 3 | Symmetry，使用与 Result 2 一致的页面模板 |
| 11 | 综合回答研究问题 | 汇总三个分析轴分别提供了什么证据 |
| 12 | Conclusion / Future work | 回答开头问题，保留必要限制和后续工作 |
| 13+ | References / Appendix | 公式、严格定义、补充图表、可能的答疑材料 |

## 5. Results 命名决定

保留清晰的编号形式：

- Result 1
- Result 2
- Result 3

不把栏目名称改成 Main Result、Exploratory Result 或 Negative Result。

证据强弱改由以下方式体现：

- Result 1 使用两页和最多讲解时间。
- Result 2 的标题和结论必须明确：不存在干净的全局单调规律，只识别到小规模高置信 subgroup。
- Result 3 的标题和结论必须明确：symmetry alone 不能形成稳定解释。
- 三项结果虽然编号并列，但不得在结论强度上写成三个同等强度的正发现。

## 6. Experimental setup 必须补足的范围

旧课件第 5 页有方法摘要，但不足以建立完整实验图景。新版本至少应覆盖：

- FB15k-237。
- RotatE 与 TransE。
- 同一模型家族、不同随机种子的 repeated runs。
- `without` voting 条件。
- query-level top-10 hit/miss 到 relation-level 指标的聚合。
- Hits@10、Alpha、Delta。
- Alpha/Delta 使用 eligible subset。
- 主显示条件 `test_support >= 10`。
- mapping type 主结果按 prediction side 分析。
- 当前实验属于本论文的 repeated-run protocol，不表述为原论文完整 competing-model protocol 的精确复现。

## 7. Result 2 / Result 3 的统一规则

老师反馈的重点是减少两页之间的重新学习成本。两页应统一：

- 标题位置和字号。
- 一句话 key finding 的位置。
- 表格区域大小。
- 列顺序和指标顺序。
- RotatE / TransE 的排列方式。
- 右侧解释区域的位置。
- 强调色和重点数字的使用方式。

制作时以论文现行 inverse / symmetry 表格为数据来源。旧课件第 9、10 页的表格数值和结构不直接复用。

## 8. `0.pdf` 复用范围

### 可以重点借用

- 第 2 页：KG、link prediction、Hits@10 的基本解释思路。
- 第 3 页：predictive multiplicity 的 toy example。
- 第 4 页：从 prior work 过渡到 thesis question 的逻辑。
- 第 7、8 页：mapping-type 图表资产和两页展开方式。
- 第 13、14 页：作为答疑附录的理论定义框架。

### 只保留方向，重新制作

- 第 5 页：改造成完整的 Experimental Setup 流程图。
- 第 6 页：改造成 research question / analysis axes；relation frequency 不与三个已完成结果等量并列。
- 第 11 页：根据最终课件的证据结构重新组织总结。

### 不直接复用

- 因果性过强或超过当前证据边界的结果措辞。
- 把 inverse 和 symmetry 表述成与 mapping type 同等强度正结果的表达。

## 9. 证据边界

- Mapping type 是当前最清楚的结果，但只表述为强关联和明显的 side-dependent pattern，不声称完全解释 multiplicity。
- Inverse-like support 是 subgroup-level observation，不声称存在全局单调规律。
- Symmetry 是弱或负结果，不能省略，也不能写成独立的稳定解释因素。
- Relation frequency 目前是待定的 support / sparsity control，不提前写结论。
- Result 2、Result 3 的最终数值必须取自论文现行版本，不从 `0.pdf` 手工沿用。
- 对原论文 frequency 结果的描述，在正式写入课件前必须重新核对原始来源；不能直接使用“只有约 0.1 相关性”的说法。

## 10. 制作原则

- 每页只承担一个主要任务。
- 标题尽量直接表达该页结论或问题。
- 以不了解该研究领域的日本答辩教师为默认听众，不假设其预先理解 KGE、predictive multiplicity 或 relation-level analysis。
- 专业术语按“日常表达或例子 → 简短定义 → 正式术语 → 后续统一使用”的顺序引入。
- 在定义 `relation` 之前，口语中优先使用 `type of link`；定义后再稳定使用 `relation`。
- 课件文字可以保持必要的学术正式性；英语口语稿使用短句、常用词和清楚的停顿，避免不必要的书面词、长从句和习语。
- 口语稿不使用 Markdown 引用符号，便于直接复制。
- Setup 虽然控制在一页左右，但不是可省略内容。
- Result 1 获得最多视觉面积和讲解时间。
- Result 2、Result 3 采用相同视觉语法。
- 优先减少文字密度，不通过缩小字号塞入内容。
- 旧课件用于回收素材，新课件整体重新组织。

## 11. 尚未固定的事项

- 最终总页数和每页精确讲解时间。
- 是否保留单独的目录页。
- 课件最终使用英语、日语，还是标题与解释混合。
- Result 2 最终采用哪一张现行论文表格及需要保留的 subgroup 行。
- 综合回答研究问题是否单独占一页，或与 Conclusion 合并。
- 最终视觉模板及其与旧课件蓝色页眉风格的继承程度。
