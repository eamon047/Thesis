\section{Analysis Design}
\label{chap:framework}

The previous chapter reviews predictive multiplicity and its use in KGE-based
link prediction. This chapter describes the analysis design used in this
thesis. It explains how comparable repeated runs are constructed, how their
query-level outcomes are aggregated by relation and prediction side, and how
the three relation patterns are computed from the training graph.

\subsection{Comparable Repeated-Run Setting}

For each model family, we use the training configuration selected through the
hyperparameter optimization in the original study
\citep{zhu2024predictive}. One run trained with this configuration is fixed as
the reference model, and additional runs use the same configuration with
different random seeds. Let $H_0$ be the filtered Hits@10 of the reference run
and $H_i$ the filtered Hits@10 of a candidate run. A candidate is included in
the comparable set when
\begin{align}
    |H_i-H_0| < \epsilon,
    \qquad \epsilon=0.001.
\end{align}
This process is repeated until the outputs required for the multiplicity
analysis have been collected. The performance condition keeps the comparison
within a small neighborhood of aggregate link-prediction performance, while
the different random seeds allow query-level decisions to vary. The reference
run is fixed before the relation-level analysis and provides the reference
output used in the multiplicity measures below.

Figure~\ref{fig:experimental-workflow} summarizes the repeated-run setting and
the subsequent relation-level analysis.

\subsection{Relation-Level and Side-Aware Aggregation}

Each test triple gives a head-prediction query and a tail-prediction query, as
described in Chapter~\ref{chap:background}. For relation $r$, let
$\mathcal{Q}^{\mathrm{head}}_r$ and $\mathcal{Q}^{\mathrm{tail}}_r$ denote the
corresponding query sets. Their union is
\begin{align}
    \mathcal{Q}_r
    =
    \mathcal{Q}^{\mathrm{head}}_r
    \cup
    \mathcal{Q}^{\mathrm{tail}}_r.
\end{align}
If relation $r$ appears in $n_r$ test triples, then
$|\mathcal{Q}^{\mathrm{head}}_r|=|\mathcal{Q}^{\mathrm{tail}}_r|=n_r$ and
$|\mathcal{Q}_r|=2n_r$. We refer to $n_r$ as the test support of relation
$r$.

The analysis first computes performance and multiplicity for each relation
separately. This makes relations, rather than individual test items, the units
compared across relation patterns. It also avoids reporting only a test-set
average dominated by relations with high test support.

The prediction side is retained when it is part of the relation pattern. For a
$1$-$N$ relation, tail prediction targets the many-valued side, whereas head
prediction targets the opposite side. For an $M$-$1$ relation, the roles are
reversed. The main mapping-type analysis therefore uses
$\mathcal{Q}^{\mathrm{head}}_r$ and $\mathcal{Q}^{\mathrm{tail}}_r$ separately
instead of relying only on the combined set $\mathcal{Q}_r$.

\subsection{Relation-Level Metrics in This Thesis}

Let $\mathcal{O}=\{o_1,\ldots,o_m\}$ be the complete evaluation outputs of the
comparable repeated runs. Each evaluated item is written as $\tau=(q,e)$,
where $q$ is a head- or tail-prediction query and $e$ is its held-out correct
answer. For relation $r$, let $\mathcal{T}_r$ be the set of evaluated items
whose query contains $r$. For output $o\in\mathcal{O}$, define the top-$k$
decision
\begin{align}
    T_k(o,\tau) =
    \begin{cases}
        1, & \text{if output } o \text{ ranks } e \text{ within top-}k,\\
        0, & \text{otherwise.}
    \end{cases}
\end{align}
The experiments use $k=10$.

Relation-level Hits@10 averages this decision over the evaluated items of a
relation and over the repeated outputs:
\begin{align}
    hits_r
    =
    \frac{1}{|\mathcal{O}|\,|\mathcal{T}_r|}
    \sum_{o\in\mathcal{O}}
    \sum_{\tau\in\mathcal{T}_r}
    T_k(o,\tau).
\end{align}
For a side-specific result, $\mathcal{T}_r$ is replaced by the corresponding
head- or tail-prediction evaluated-item set.

The multiplicity measures use a relation-specific eligible subset:
\begin{align}
    \mathcal{T}^{\mathrm{elig}}_r
    =
    \{\tau\in\mathcal{T}_r
    \mid \max_{o\in\mathcal{O}} T_k(o,\tau)=1\}.
\end{align}
It contains the evaluated items for which at least one repeated output ranks
the correct answer within top-$k$. Items missed by every output are shared
failures and are excluded from the denominator of the multiplicity measures.

Let $o_0$ be the fixed reference output. The conflict indicator is
\begin{align}
    \Delta(o,\tau)
    =
    \mathbf{1}\!\left[T_k(o,\tau)\neq T_k(o_0,\tau)\right].
\end{align}
Relation-level ambiguity is
\begin{align}
    \alpha_r
    =
    \frac{1}{|\mathcal{T}^{\mathrm{elig}}_r|}
    \sum_{\tau\in\mathcal{T}^{\mathrm{elig}}_r}
    \max_{o\in\mathcal{O}}
    \Delta(o,\tau).
\end{align}
It is the proportion of eligible items for which at least one repeated output
conflicts with the reference output. Relation-level discrepancy is
\begin{align}
    \delta_r
    =
    \max_{o\in\mathcal{O}}
    \frac{1}{|\mathcal{T}^{\mathrm{elig}}_r|}
    \sum_{\tau\in\mathcal{T}^{\mathrm{elig}}_r}
    \Delta(o,\tau).
\end{align}
It is the largest hit-or-miss disagreement between one repeated output and the
reference output for relation $r$. Because both denominators use
$\mathcal{T}^{\mathrm{elig}}_r$, $\alpha_r$ and $\delta_r$ describe
instability among items where success is observed at least once. They are not
error rates over all test queries of the relation.

\subsection{Operational Definitions of Relation Patterns}

Chapter~\ref{chap:background} introduces the general relation patterns used in
this thesis. The present analysis computes mapping type, inverse support, and
symmetry from the training graph. These three patterns can be summarized for
individual relations and compared with the relation-level metrics above.
Composition and transitivity require relation-path analysis and are outside the
current design.

Let the training graph be
\begin{align}
    \mathcal{G}_{\mathrm{train}}
    \subseteq
    \mathcal{E}\times\mathcal{R}\times\mathcal{E}.
\end{align}
For each relation $r$, its directed edge set is
\begin{align}
    E_r
    =
    \{(h,t)\mid(h,r,t)\in\mathcal{G}_{\mathrm{train}}\}.
\end{align}
All relation-pattern variables below are computed from
$\mathcal{G}_{\mathrm{train}}$.

\subsubsection{Mapping Type}

Following the convention used in the experiments
\citep{bordes2013translating}, two average connectivity values are computed:
\begin{align}
    d_{\mathrm{tail}}(r)
    &=
    \frac{|E_r|}
    {|\{h\mid \exists t,\ (h,t)\in E_r\}|},
    \\
    d_{\mathrm{head}}(r)
    &=
    \frac{|E_r|}
    {|\{t\mid \exists h,\ (h,t)\in E_r\}|}.
\end{align}
$d_{\mathrm{tail}}(r)$ is the average number of tails per observed head, and
$d_{\mathrm{head}}(r)$ is the average number of heads per observed tail. A
side is classified as many when its corresponding value is greater than
$1.5$. Combining the two classifications gives the $1$-$1$, $1$-$N$,
$M$-$1$, and $M$-$N$ types introduced in
Chapter~\ref{chap:background}.

The mapping-type analysis is side-aware. Tail prediction is treated as
prediction on the many side for $1$-$N$ relations, and head prediction is
treated as prediction on the many side for $M$-$1$ relations. This distinction
determines the head- and tail-specific grouping used in
Chapter~\ref{chap:experiments}.

\subsubsection{Inverse Support}

For relation $r$, define the reversed edge set
\begin{align}
    E_r^{\mathrm{rev}}
    =
    \{(t,h)\mid(h,t)\in E_r\}.
\end{align}
For an ordered pair $(r_1,r_2)$, the directional inverse score is
\begin{align}
    s(r_1\rightarrow r_2)
    =
    \frac{|E_{r_1}\cap E_{r_2}^{\mathrm{rev}}|}{|E_{r_1}|}.
\end{align}
It is the proportion of $r_1$ edges supported by reversed $r_2$ edges. The
score is directional, so $s(r_1\rightarrow r_2)$ and
$s(r_2\rightarrow r_1)$ need not be equal.

Because a directional score can be high under one-sided containment, the main
inverse analysis uses a stricter mutual score. Let
\begin{align}
    s_{12}=s(r_1\rightarrow r_2),
    \qquad
    s_{21}=s(r_2\rightarrow r_1).
\end{align}
The pair-level mutual inverse score is
\begin{align}
    s_{\mathrm{mut}}(r_1,r_2)
    =
    \begin{cases}
        \dfrac{2s_{12}s_{21}}{s_{12}+s_{21}},
        & \text{if }s_{12}+s_{21}>0,\\
        0, & \text{otherwise.}
    \end{cases}
\end{align}
This harmonic mean is high only when both directions have substantial reverse
support.

For each relation, the strongest mutual inverse partner gives
\begin{align}
    \operatorname{MutInvStrength}(r)
    =
    \max_{r'\in\mathcal{R},\,r'\neq r}
    s_{\mathrm{mut}}(r,r').
\end{align}
Inverse clarity measures the separation between the strongest and second
strongest partners:
\begin{align}
    \operatorname{InvClarity}(r)
    =
    \max\!\left(
        0,\,
        \operatorname{MutInvStrength}(r)
        -
        \operatorname{SecondBestMutInvStrength}(r)
    \right).
\end{align}
\subsubsection{Symmetry}

For relation $r$, define the edge set supported in both directions under the
same relation:
\begin{align}
    E_r^{\mathrm{sym}}
    =
    \{(h,t)\in E_r\mid(t,h)\in E_r\}.
\end{align}
The raw symmetry score is
\begin{align}
    \operatorname{Sym}(r)
    =
    \frac{|E_r^{\mathrm{sym}}|}{|E_r|}.
\end{align}

Self-loops can inflate this score because reversing $(h,r,h)$ gives the same
edge. The main symmetry variable therefore excludes self-loops. Define
\begin{align}
    E_r^{\neg\mathrm{loop}}
    &=
    \{(h,t)\in E_r\mid h\neq t\},
    \\
    E_r^{\mathrm{sym},\neg\mathrm{loop}}
    &=
    \{(h,t)\in E_r\mid h\neq t,\ (t,h)\in E_r\}.
\end{align}
The excluding-self-loop score is
\begin{align}
    \operatorname{Sym}^{\neg\mathrm{loop}}(r)
    =
    \frac{|E_r^{\mathrm{sym},\neg\mathrm{loop}}|}
    {|E_r^{\neg\mathrm{loop}}|}.
\end{align}
When $|E_r^{\neg\mathrm{loop}}|=0$, the implementation sets this score to
$0$. The experiments use $\operatorname{Sym}^{\neg\mathrm{loop}}(r)$ as the
main symmetry variable and retain the raw score only to check self-loop
sensitivity.

Low symmetry is not treated as antisymmetry. The quantity
$1-\operatorname{Sym}^{\neg\mathrm{loop}}(r)$ shows only a lack of observed
same-relation reverse support, whereas strict antisymmetry is a stronger
mathematical condition.
